A tiny stack VM for [make.fun's tiny-stack-vm-01 bounty](https://make.fun/bounty/tiny-stack-vm-01-run-20261122): one plain `main.ts` (Node 22, no dependencies) runs all 40 instances — 32-bit wrapping arithmetic, 256-value stack, 64-deep calls, 256 words of memory, and all ten traps with their exact exit codes. Run: `node main.ts`.
